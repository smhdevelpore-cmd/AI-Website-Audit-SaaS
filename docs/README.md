# AI Website Audit SaaS --- MVP Documentation Pack

Included: - PRD.md --- product scope, users, requirements, acceptance
criteria, success metrics - Design.md --- UX principles, IA, page specs,
components, PDF and states - TRD.md --- stack, API contracts, job flow,
crawler security, DB/RLS, tests, deployment - ARD.md --- architecture,
decisions, flows, trust boundaries, threats and reliability

MVP target: small digital marketing agencies and freelance web
developers.

Core workflow: sign in → submit public URL → bounded async audit →
evidence-based findings/scores → AI explanations/action plan →
client-ready PDF → history.

Scope exclusions: rank tracking, backlinks, GSC/GA, auto-fixes, full
compliance certification, CRM, team/client portal, recurring audits and
unlimited crawl.

First proof milestone: scan one real public site with actual
metrics/findings and produce a useful PDF from stored results.
